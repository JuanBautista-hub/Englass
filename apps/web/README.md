# `@engclass/web`

Angular 17+ frontend for Engclass. Implements `openspec/specs/frontend-system-prompt/spec.md`.

## Install

```sh
# from the monorepo root
pnpm install
```

## Build the demo PDF fixture

```sh
pnpm --filter @engclass/web fixtures:build
```

The fixture is written to `apps/web/src/assets/fixtures/demo.pdf` and is loaded by the mock API.

## Scripts

```sh
pnpm --filter @engclass/web start         # ng serve on http://localhost:4200
pnpm --filter @engclass/web build         # ng build → dist/apps/web/
pnpm --filter @engclass/web test          # jest (jsdom)
pnpm --filter @engclass/web lint          # eslint, zero warnings
pnpm --filter @engclass/web typecheck     # tsc -p tsconfig.app.json --noEmit
```

## Default route

The app boots at `/` and redirects to `/editor/demo`. With `environment.useMockApi === true` (the default), the page loads the bundled demo PDF and persists annotations in memory; no backend is required.

## Toggling the mock

`apps/web/src/environments/environment.ts` exports:

```ts
export const environment = {
  production: false,
  apiBaseUrl: 'http://localhost:3000/api/v1',
  useMockApi: true,   // flip to false to point at a real backend
  cookieDomain: 'localhost',
};
```

The `production` build replaces this with `src/environments/environment.production.ts` (`useMockApi: false`).

## Environment variables

- `API_BASE_URL`: base URL of the backend (default `http://localhost:3000/api/v1`). The Angular application builder substitutes it at build time via `fileReplacements`.
- `COOKIE_DOMAIN`: domain attribute set on auth/CSRF cookies (default `localhost`). The backend sets this on the `Set-Cookie` header.

## Architecture

See `openspec/specs/angular-frontend/spec.md` for the full requirements this app implements. The prompt `front-prompt.md` at the repo root is the AI-assistant-facing specification; this codebase is its concrete realization.

## Mock backend

When `environment.useMockApi === true`, every `HttpClient` call is intercepted by `mockBackendInterceptor` (registered before `csrfInterceptor` in `app.config.ts`). The interceptor delegates to `MockApiService.handle(...)` and synthesizes an `HttpResponse` event. The demo PDF is bundled as a base64 constant in `core/services/demo-pdf.b64.ts` (regenerated by `pnpm --filter @engclass/web fixtures:build`) and served synchronously as an `ArrayBuffer`.

A `console.warn('[Engclass] Mock API is active - no real backend is being called.')` is emitted once at bootstrap when the mock is on.
